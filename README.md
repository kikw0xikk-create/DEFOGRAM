Overview

DEFOGRAM is an iOS project focused on customization, privacy-oriented tools, advanced chat organization, and personal collections.

Built with SwiftUI and designed around Apple’s Liquid Glass visual language.

Features

🎨 Visual Engine

* Liquid Glass interface
* AMOLED Black theme
* Custom colors and gradients
* Custom fonts and message bubbles
* Individual chat themes
* Custom wallpapers

👻 Privacy Engine

* Privacy settings interface
* Face ID protection concept
* Local message history concept
* Hidden chats interface
* Cache management

💬 Chats Engine

* Chat organization
* Custom folders
* Pinned chats
* Search and filtering
* Multi-account interface

🎁 Gifts Archive

* Local gift collection
* Custom gift cards
* Historical gift archive structure
* Collectible metadata

⭐ Local Stars

* Local Stars simulator
* Custom balance
* Transaction history
* Add and spend simulated Stars

💎 NFT Studio

* Local collectible cards
* Custom NFT metadata
* Personal collection management

👤 Local Identity Studio

* Create custom local profiles
* Custom usernames
* Custom names and bios
* Custom profile pictures
* Custom country selection
* Custom display phone numbers
* Regular and collectible number styles

Local profiles, usernames, phone numbers, Stars, and collectibles are visual/local-only features. They do not register Telegram identities, transfer real Stars, or create blockchain assets.

Build

1. Open the project in Xcode.
2. Configure the Bundle Identifier.
3. Configure Apple Developer signing.
4. Select an iOS deployment target.
5. Build and archive the application.
